## Configuration Details

### DNS Configuration

**Required DNS Records:**

```dns
# A Records (or CNAME to Coolify server)
@                       A      1.2.3.4
www                     A      1.2.3.4
api                     A      1.2.3.4

# Staging (optional)
staging                 A      1.2.3.4
staging-api             A      1.2.3.4

# Where 1.2.3.4 is your Coolify server IP
```

### Coolify Domain Configuration

**Backend Service:**

1. Navigate to `smarter-team-backend` in Coolify
2. Click "Domains" tab
3. Add domain: `api.smarter-team.com`
4. Enable SSL: ✓ (Let's Encrypt)
5. Enable force HTTPS: ✓
6. Save

**Frontend Service:**

1. Navigate to `smarter-team-frontend` in Coolify
2. Add domains:
   - `smarter-team.com`
   - `www.smarter-team.com`
3. Enable SSL: ✓
4. Enable force HTTPS: ✓
5. Redirect www → non-www: ✓

### Nginx Configuration (Coolify Auto-Generated)

```nginx
# Auto-generated by Coolify
server {
    listen 80;
    server_name api.smarter-team.com;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name api.smarter-team.com;

    ssl_certificate /etc/letsencrypt/live/api.smarter-team.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/api.smarter-team.com/privkey.pem;

    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;
    ssl_prefer_server_ciphers on;

    # HSTS
    add_header Strict-Transport-Security "max-age=31536000; includeSubDomains; preload" always;

    location / {
        proxy_pass http://smarter-team-backend:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

## Security Best Practices

1. **HSTS**: Force HTTPS for 1 year
2. **Certificate transparency**: Monitor CT logs
3. **TLS 1.2+**: Disable older protocols
4. **Strong ciphers**: No weak/deprecated ciphers
5. **OCSP stapling**: Enable for faster cert validation

## Troubleshooting

**DNS not resolving:**
- Wait for DNS propagation (up to 48 hours)
- Check DNS records at registrar
- Test with `dig` or `nslookup`

**SSL certificate generation fails:**
- Verify DNS points to Coolify server
- Check port 80/443 are accessible
- Review Let's Encrypt rate limits
- Check Coolify logs for errors

**HTTPS not working:**
- Verify SSL certificate is valid
- Check Nginx configuration
- Ensure firewall allows 443
- Test with `curl -k` to bypass SSL validation

**WWW redirect not working:**
- Verify both domains added in Coolify
- Check redirect rule in Nginx config
- Clear browser cache
