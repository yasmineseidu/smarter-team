## Purpose

Build an autonomous AI agent team that runs an AI agency from lead generation to client delivery, enabling a solopreneur to scale from 0 to 8 figures.

## Target Users

1. **Primary**: You (Solopreneur/Admin)
   - Full system control
   - Agent configuration
   - Human-in-the-loop decisions

2. **Secondary**: Contractors/Freelancers
   - Task-specific access
   - View assigned work

3. **Agents**: 8 AI agents
   - Autonomous operation
   - Inter-agent communication

## Success Criteria

1. Agents autonomously handle 80%+ of operations
2. Close deals with minimal human intervention
3. Deliver client projects on time
4. Scale to 50+ clients without proportional effort
5. Revenue exceeds operational costs significantly
